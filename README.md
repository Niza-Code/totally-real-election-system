## About
The most gloriously broken democracy platform ever created. This is a parody e-voting system that celebrates every flaw in electronic voting with the energy of "Oh... Anyway."

## Features
- Unlimited Voting™ (vote as many times as you want)
- Undo Vote (democracy with buyer's remorse)
- Community Moderation (anyone can delete any poll)
- The Pigeon (eternal default candidate)
- Brian (our server administrator, currently going through some things)
- BLOCKCHAIN™ (we use the word a lot)

## Tech Stack
- Frontend: React + Vite
- Backend: Node.js + Express
- Database: PostgreSQL (ironically reliable for this)
- Security: None (intentional)

## Disclaimer
⚠️ THIS IS A PARODY. THIS IS NOT AN OFFICIAL VOTING SYSTEM.
